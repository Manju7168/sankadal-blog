# Sankadal village blog

A buildless HTML/CSS/JavaScript blog. Kannada is the default. The language buttons translate every story and remember the visitor’s choice in browser localStorage when available. Comments are deferred to phase two.

## Preview

Open index.html in a browser. No Java, Node.js, or build step is required. Google Fonts are optional; system fonts are used if unavailable.

## Publish free on GitHub Pages

1. Create a public GitHub repository, for example `sankadal-blog`.
2. Upload index.html, style.css, script.js, the assets folder and .nojekyll to the repository root. Ensure index.html is not inside an extra folder.
3. Go to repository Settings → Pages.
4. Under Build and deployment, select Deploy from a branch.
5. Choose main and /(root), then Save.
6. GitHub will display the published URL, typically https://YOUR-USERNAME.github.io/sankadal-blog/.

You do not need a personal access token for uploads through GitHub’s website.

## Update content

Kannada text is in index.html. English translations are in the `english` object in script.js. Match each data-i18n key to its English entry. Add new articles in both languages. The full report is organized into 11 sections in both Kannada and English. Report text is static HTML in the data-report-language panels in index.html. Keep both panels in sync. The original Kannada PDF and all 13 page facsimiles are in assets/.

## Sources and imagery

Factual content is attributed to all 13 pages of the user-shared Sankadal_Village_History_Census_Kannada.pdf. All 27 references, population/social-group/literacy/employment/land-use/amenity tables, administrative history, inscription evidence, community coverage, timeline and research gaps are retained. The old Kannada inscription transcription is preserved as a facsimile to avoid introducing transcription errors; a provisional line-by-line interpretation appears in both language editions. Original historical/census sources have not been independently verified. The inscription date is explicitly an estimate. The landscape is decorative CSS artwork, not a village photograph. No private email address or email link is included in the website.
